# SQGI v0.1.7-alpha

This source release enables the LLVM JIT and typed kernel compiler by default.
Both use LLVM 18. It also includes the runtime, packaging, Cairo, and Windows
fixes accumulated since v0.1.6-alpha.

## Changes

- LLVM compilation of eligible Squirrel functions/loops, typed kernel modules
  and helper calls, and interpreter/runtime optimizations.
- Faster JSON parsing/serialization and additional runtime regression coverage,
  including cached table members and methods across table growth.
- Simpler version-2 sqgipkg manifests, native Windows packaging, kernel payload
  packaging, and Windows Unicode/argument/path handling fixes.
- Cairo wrapper type safety, source patterns, ownership tests, and checker
  metadata improvements.
- Editor highlighting/formatting, expanded documentation, and LLVM 18 build
  compatibility fixes for GCC 15.

The sqgipkg GUI is under development and is not part of this release.
The shared-library ABI remains version 1.

## Build

On Ubuntu 24.04, install the build dependencies:

```sh
sudo apt install cmake build-essential pkg-config \
  libglib2.0-dev libgirepository1.0-dev libffi-dev libcairo2-dev llvm-18-dev
```

Explicitly configure the defaults when reusing an older build directory:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
  -DSQ_ENABLE_JIT=ON -DSQGI_BYTECODE_JIT_BACKEND=LLVM \
  -DSQGI_ENABLE_KERNELS=ON -DSQGI_KERNEL_BACKEND=LLVM
cmake --build build --parallel
build/sqgi --version
ctest --test-dir build --output-on-failure
```

The executable and pkg-config metadata report `0.1.7-alpha`.

## Validation

Validated on Ubuntu 24.04 x86_64 in Release mode with LLVM 18.1.3, the LLVM
bytecode JIT enabled, and typed LLVM kernels enabled.

- All 148 registered CTests passed across the full run and affected-test reruns.
- The packaging suite built and ran real AppImages, including native GI
  fixtures; the kernel packaging regression also passed.
- `sqgi --version`, `sqgicheck --version`, runtime version metadata, and
  pkg-config agree on `0.1.7-alpha`.
- Updated stale packaging help assertions for the existing native CLI parser.

Native Windows and AArch64 execution were not rerun as part of this release
check. Platform-dependent packaging subchecks retain their existing tool-based
skip behavior; the CTest count does not imply execution on those platforms.
