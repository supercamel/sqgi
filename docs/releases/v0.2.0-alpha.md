# SQGI v0.2.0-alpha

This release fixes Windows LLVM JIT crashes and adds a GTK editor for sqgipkg
application manifests.

## Windows LLVM execution

- Fix intermittent relocation failures when running JIT-compiled Squirrel and
  typed kernels on Windows.
- Fix linking of floating-point constants in generated Windows code.
- Fix duplicate MinGW unwinder symbols when building SQGI's C++ components.

LLVM JIT and typed kernels remain enabled by default and require LLVM 18.

## Manifest authoring

Launch `sqgipkg-gui` to edit an application's packaging manifest. The editor
provides Check and Explain actions through `sqgipkg` so you can inspect the
selected configuration before building.

See the [packaging guide](../packaging/README.md) for application manifests,
native modules and distribution targets.

## Compatibility

The application and pkg-config version is `0.2.0-alpha`. The shared-library ABI
version remains `1.0.0` (SOVERSION 1).
