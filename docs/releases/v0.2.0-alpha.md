# SQGI v0.2.0-alpha

This minor release fixes Windows LLVM JIT crashes, expands native Windows CI
coverage, and includes the sqgipkg manifest editor introduced after v0.1.7-alpha.

## Windows LLVM execution

- Fix the intermittent COFF relocation abort by keeping each generated object's
  sections within one ordered Windows memory reservation. Bytecode JIT and
  typed kernels share the fix.
- Handle floating-point constant symbols when linking generated Windows objects.
- Fix duplicate MinGW unwinder exports that prevented C++ tests from linking.
- Add a Wine test runner that avoids false timeouts caused by background Wine
  processes retaining the test's output pipe.

LLVM JIT and typed kernels remain enabled by default. Native Windows CI checks
those defaults, runs the full JIT/kernel selection, repeats the performance and
matrix regressions 30 times each, and uploads diagnostic logs even on failure.

## Manifest authoring

`sqgipkg-gui` is a GTK manifest editor under `tools/sqgipkg_gui`, with a tree of
requirements, implementation contracts and contract tests. Manifest authoring is
its primary purpose. Check/Explain delegate to `sqgipkg`; packaging logic remains
in `sqgipkg`.

## Validation

- Windows x86-64 under Wine: 60/60 JIT/kernel tests passed.
- Linux: the equivalent 60/60 tests passed.
- The Windows performance and matrix regressions each passed 30 consecutive runs.
- All three Linux manifest-editor CTest groups passed after the version bump.
- Rebuilt Linux and Windows executables, Linux `sqgicheck`, and pkg-config
  metadata report `0.2.0-alpha`.
- Native Windows execution is covered by the updated CI workflow; a runner pass
  is not claimed by the local Wine results.

See [the Windows LLVM validation report](../windows-llvm-wine.md) for the tested
toolchain, failure analysis, scope and reproduction commands. Packaging tests
are separate from the Wine runtime selection and remain in native Windows CI.

The application and pkg-config version is `0.2.0-alpha`. The shared-library ABI
version remains `1.0.0` (SOVERSION 1).
