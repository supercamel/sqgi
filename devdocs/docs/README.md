# Development documentation archive

This directory contains implementation plans, design reviews, audits, test
reports and benchmark records moved out of the user documentation. These are
historical development records; their status, commands and conclusions may
describe earlier versions of SQGI.

Use the repository's root `docs/` directory for current user guides, tutorials,
API references, recipes and release notes. Keep implementation planning and
validation evidence here. MkDocs publishes only root `docs/`; do not add this
archive to its navigation or link user guides to it as required reading.

Original versions of mixed pages are retained alongside the internal reports.
Their current user-facing versions remain under root `docs/`. The README's
public benchmark datasets live in `demo/benchmarks/results/`.
