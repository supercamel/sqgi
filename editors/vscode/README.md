# SQGI for Visual Studio Code

Syntax highlighting and document formatting for **SQGI Squirrel (`.nut`)** and
**typed kernels (`.sqk`)**. Includes async/await, comments, escaped and verbatim
strings, kernel types and math functions, bracket matching, auto-closing pairs,
and indentation rules.

The extension runs its formatter inside VS Code. It needs no separately installed
SQGI, Node.js, language server, or formatter package. It works in untrusted and
virtual workspaces and does not execute your source code.

## Install

Requires VS Code 1.85 or newer. From the repository root, build the local VSIX
using Node.js 22 or newer:

```sh
cd editors/vscode
npm ci
npm run package
code --install-extension sqgi-0.1.0.vsix
```

Alternatively, run **Extensions: Install from VSIX…** in the Command Palette
and select the generated file. Node.js is only needed to build the VSIX. This extension has not
been published to the Marketplace.

Open a `.nut` or `.sqk` file and choose **Format Document** from the Command
Palette. For format-on-save, merge these settings into **Preferences: Open User
Settings (JSON)** or the project’s `.vscode/settings.json`:

```json
{
  "[sqgi-squirrel]": {
    "editor.defaultFormatter": "supercamel.sqgi",
    "editor.formatOnSave": true
  },
  "[sqgi-kernel]": {
    "editor.defaultFormatter": "supercamel.sqgi",
    "editor.formatOnSave": true
  }
}
```

If another Squirrel extension owns `.nut` files, choose **SQGI Squirrel** using
**Change Language Mode**, or set `"files.associations": { "*.nut": "sqgi-squirrel" }`.
The formatter honors the editor's tab size and spaces/tabs setting (1–16 columns).

## Formatting behavior

This first formatter normalizes indentation and horizontal spacing while
preserving line breaks, semicolons, comments, and literal contents. It does not
wrap lines, split single-line statements, sort imports, or convert quotes.
Squirrel's optional semicolons make line-break preservation significant.
Incomplete strings, comments, or delimiters produce a warning and no edit. The
formatter also verifies that token spelling and line boundaries remain intact.
These checks are lexical safeguards, not a replacement for `sqgicheck`.

For the shared CLI and GtkSourceView integration, see `editors/README.md` in the
SQGI repository. The same formatter handles both languages.

## Development

```sh
npm test
```

Grammars are generated by `python3 editors/generate-languages.py` from the
repository root. Update `editors/language-data.json` to change the vocabulary.
